***Variables:*** Contains the data so it can be manipulated
***Data types:*** Describes the type of data in a [[variable]]
> ([[Book IntroductionC.pdf#page=29&annotation=4700R|Book IntroductionC, p.29]])
> A *[[variable]]* is a place in the computer’s memory

### Data types
**int**, or an integer is an whole number that can be written without a fractional component. A.E.: 0, +1, +2, -3, -4
(Integers in [[C]] can have ***`+`*** or ***`-`*** signs, also ***`1`*** and ***`+1`*** are the same)

> integer from the Latin integer, meaning "whole"
