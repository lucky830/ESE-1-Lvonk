Most often used in a `printf()` [[function]]:
	*newline*: `\n`
	*tab*    : `\t`

The **newline** character introduces a new line in the terminal output. 
And the **tab** character introduces multiple spaces in a line

you can use the `\` as an escape character so `\\n` prints literally `\n`

| **Character(s)** | **Escape sequence** | **Result** |
|:---------------- |:------------------- |:---------- |
| double quote     | `\"`                | `”`        |
| single quote     | `\'`                | `’`        |
| \n (lit)         | `\n`                | \n`        |
| \t (lit)         | `\t`                | `\t`       |
| % (lit)          | `\%`                | `%`        |
| \A (lit)         | `\A`                | `\A`       |
| \                | `\\`                | `\`        |
